## 2.10.0 的路线图交付与验收

| 原优先级 | 已交付的操作 | 回归重点 |
| --- | --- | --- |
| P0 | 在「提交待核实」录入官网编号，先查该连接的账户记录，再确认关联。可单独记录已在服务商人工核对的结果。[找回实现](../src-tauri/src/receipts.rs) | 正确编号取回原结果，查不到、模板不符或重复关联时保留原记录。找回只查询和下载。 |
| P1 | 剧本中的「镜头队列与预算」逐镜核对模型、队列和费用，先保存待发清单，再开始发送。并发按连接限制，已发任务按原编号追踪。[队列](../src-tauri/src/batches.rs) | 两镜各选两个模型共四次提交。撤回其中一项，服务端只收到三次。未知价单列，已知预估超预算时可以调整范围。 |
| P1 | 在有图片输入的创作方式中，将有序图片、名称和描述存为角色卡或场景卡，换镜后可以继续引用。[素材卡](../desktop/ui/ReferenceCards.tsx) | 入卡和入队的本地图片保存独立内容副本。后续改卡、移动原图或替换第二镜的参考不会改动第一镜历史。 |
| P1 | 按剧本顺序检查缺片、预览各镜、测量实际时长，导出带镜号的图、视频和台词。可取当前画面作为下一镜首帧，或用 FFmpeg 合成 MP4。[整片交付](../desktop/ui/FilmPreview.tsx) | 三镜缺片时定位到对应镜头。调序后逐镜文件、连续播放和台词清单逐项一致，同时保留原件。 |
| P1 | 按剧本生成单个 `.mobius` 归档，导入前查看镜头、候选、草稿、缺件与重名数。每次导入使用独立项目编号。[归档](../src-tauri/src/project_archive.rs) | 在空数据目录恢复，移走来源后仍可查看定稿和参考。导入历史任务并重启，新增生成请求为零。凭据和签名下载地址排除在归档外。 |
| P2 | 按连接中的具体模型声明参考图上限、尺寸、首尾帧、遮罩和原生多结果能力，分别显示目录记录、用户声明和成功任务实测。[能力记录](../src-tauri/src/model_features.rs) | 切换模型保留已有输入，明确提示不兼容项。一次原生多结果生成按实际返回数记实测。 |

同模型可取 1、2、4 张候选。支持原生多结果的 OpenAI 兼容图片和万相图片可在一次请求中取回多张，其余连接按界面显示的次数分别提交。支持遮罩的 OpenAI 兼容图片编辑可以涂选或导入透明 PNG。作品库可按标签搜索、收藏和归档。ComfyUI 可导入 API 工作流并映射提示词、参考图与输出节点，保存前检查服务端节点与依赖模型。Windows 上还用真实 ComfyUI 0.46.0 的 CPU 服务跑通了导入图的文本绑定、参考图上传和指定结果节点，取回 1536 × 1024 PNG。[桌面验收](../tests/project-roadmap.mjs)

### 官网实测

2026 年 11 月 21 日，《潮汐灯塔》使用普通队列完成两镜。两镜原选两个图片模型，发送前撤回一项，官网实际受理三张图片。测试在官网受理第三张图后有意截断一次本地回执，客户端经账户清单关联原编号 7123000，取得同一张图。两镜分别以定稿图为参考，随后完成两段 864 × 480 的视频。合计五次生成，模板预估 ¥0.54。任务记录未提供账单实扣。合成 MP4 时长约 10.35 秒。[程序入口与操作说明](../README.md)

### 先修镜头切换与草稿恢复

在 2.5.0 前端，用同一个图生图服务和模型做了两镜测试。第一镜写“红伞特写”，选择“甲镜头红伞.png”。随后从第二镜点“用于生图”，前端把镜头改成“第 2 镜”，提示词改成“空旷的站台”。点击生成后，模拟提交仍包含“甲镜头红伞.png”。另写一条未提交的提示词，在剧本与创作台间切页可以保留，重新加载界面后回到空白。测试拦截了提交，没有产生真实生成费用。[切镜入口](../desktop/ui/App.tsx) · [草稿索引](../desktop/ui/App.tsx) · [提交时读取镜头和素材](../desktop/ui/App.tsx)

当时建议让每个镜头分别保存图片和视频草稿，包含提示词、模型、参数、首尾帧和参考素材顺序。打开新镜头时使用该镜的草稿，用户可选择沿用上一镜素材。草稿落盘需要保存可重新找到的素材引用，当前选取文件的临时编号在进程内维护。验收时，在第二镜提交前能看到准确的素材，返回第一镜或重开应用后能继续原稿。[素材编号与恢复](../src-tauri/src/store.rs)

### 作品整理与模型配置

- **整理长期积累的作品。** 目前作品库按关键词、媒体类型和任务状态查找。随着同一镜出现大量候选，可增加收藏、项目标签和归档，让日常选片更容易，也能保留旧作品与分镜的关联。即梦画布允许给重要节点加标签。[莫比环作品筛选](../desktop/ui/WorkLibrary.tsx) · [即梦资产管理](https://jimeng.jianying.com/tutorials/drama-studio/canvas)
- **每个模型单独声明能力。** 当前模型目录提取模型 ID，同连接共享协议和控制项。可允许某个模型覆盖尺寸、参考图上限、首尾帧、遮罩和多结果能力。切换时保留兼容的输入，并列出需要调整的字段，避免把服务端才会拒绝的组合交给用户试错。[模型发现](../src-tauri/src/catalog.rs) · [创作台参数来源](../desktop/ui/App.tsx)
- **导入已有的 ComfyUI 工作流。** 当前内置图使用固定节点，支持基础文生图及单张参考图重绘。可先支持导入 API 工作流，让用户标出提示词、参考图和结果节点，并检查所需节点和模型。ComfyUI 官方模板加载时会检查模型，Krita 插件也提供了调用自定义工作流的先例。[内置图](../src-tauri/src/comfy.rs) · [ComfyUI 模板](https://docs.comfy.org/interface/features/template) · [Krita 自定义工作流](https://docs.interstice.cloud/custom-graph/)

### 2.5.0 当时的优先顺序

先做镜头草稿隔离与自动保存、手工分镜、同镜候选对比。验收时，用户粘贴两镜脚本，分别选参考图、对照候选，关闭再打开后能从各镜上次的草稿与定稿继续。批量提交付费任务时，同步展示次数和已知预估。常做短片时，随后的优先项是角色参考复用和全片顺序预览。
