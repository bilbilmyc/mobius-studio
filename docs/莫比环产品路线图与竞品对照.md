## 下一阶段的开发目标

以下优先级是建议排期。每项的验收条件可以直接用于编写回归用例。

| 优先级 | 开发目标 | 完成时如何验收 |
| --- | --- | --- |
| P0 | **找回无回执的已受理任务。** 在「提交待核实」中支持录入官网任务号，先查询并显示可核对的模型、时间或结果，再由用户关联。[现有恢复入口](../src-tauri/src/lib.rs) | 模拟提交超时但服务商已受理。输入正确编号后取回原结果，全程生成 POST 只有一次。查不到、重复关联或无法核对归属时解释原因，原记录保持可核查。 |
| P1 | **按镜头排队并设置预算。** 批量前显示每镜任务数、普通或优先队列、已知预估和价格未知项。按连接限制并发，允许撤回尚未发送的镜头。[现有后台任务](../desktop/ui/BackgroundTasks.tsx) | 两镜各选两个模型时显示四次提交。预算不足时能调整范围。撤回一项后服务端仅收到三次生成，重开后能追踪已发任务。 |
| P1 | **跨镜角色卡和场景卡。** 保存可命名的参考素材和描述，提交时冻结每镜实际使用的素材及顺序。[当前素材选择](../desktop/ui/Assets.tsx) | 同一角色用于两镜。替换第二镜的参考后，第一镜草稿、已提交任务和历史定稿都保留原图。生成前可以逐张核对。 |
| P1 | **整片预览与交付。** 按镜序排列视频定稿，提示缺片、显示总时长，支持顺序预览并导出带镜号的文件及台词清单。[分镜与版本](../desktop/ui/ScriptDesk.tsx) | 三镜中一镜缺视频时定位到该镜。补齐后调整镜序，预览、清单和导出文件顺序相同，总时长按实际视频计算。 |
| P1 | **项目备份与迁移。** 将指定剧本、草稿、引用素材、候选和定稿打包，带相对路径和校验值。导入时预览涉及的镜头、缺件和重名项。[现有数据目录约定](../README.md) | 在一个空目录恢复两镜项目，移走原素材后仍能打开已有结果和草稿。重复导入不覆盖已有项目，归档中不含 API Key 或签名下载地址。 |
| P2 | **按模型记录能力与实测结果。** 同一连接允许模型分别声明参考图数量、首尾帧、遮罩、尺寸和多结果支持，并注明能力来源。[现有模型目录](../src-tauri/src/catalog.rs) | 同连接切换两个能力不同的模型时，保留兼容参数，同时指出不兼容的素材或字段。能区分目录可读、用户填写和生成实测三种状态。 |

建议先用这次真实输出完成规格核对和双模型参数对齐，再补上无回执任务找回。随后用同一部两到三镜的短片串测批量、资产和交付。

## 2.5.0 的竞品调研与原始判断

以下记录描述 2.5.0 当时的状态。表中仍保留当时尚未完成的功能，当前进度以文首的交付表为准。

2026 年 11 月 21 日核对，基于仓库提交 `02d1c49`。按个人在桌面上用多个模型做图和短片来排序，优先考虑误用素材、重复付费、选片返工和成片交付。同行功能依据官方文档，莫比环依据当前源码，并用本地模拟服务复核了切镜与草稿行为。[版本](../package.json)

莫比环已经能从分镜生成图片、逐条查看该镜的历史作品、给图片和视频分别定稿，再用定稿图和该镜视频提示词发起生成。后台支持同时处理多项任务，已取得远端编号的任务可以继续查询。作品库有搜索、筛选、图片批量导出及图片对象存储。[分镜定稿与转视频](../desktop/ui/ScriptDesk.tsx) · [作品库](../desktop/ui/WorkLibrary.tsx) · [后台任务回归场景](../tests/background-tasks.mjs) · [对象存储说明](../README.md)

### 先修镜头切换与草稿恢复

在 2.5.0 前端，用同一个图生图服务和模型做了两镜测试。第一镜写“红伞特写”，选择“甲镜头红伞.png”。随后从第二镜点“用于生图”，前端把镜头改成“第 2 镜”，提示词改成“空旷的站台”。点击生成后，模拟提交仍包含“甲镜头红伞.png”。另写一条未提交的提示词，在剧本与创作台间切页可以保留，重新加载界面后回到空白。测试拦截了提交，没有产生真实生成费用。[切镜入口](../desktop/ui/App.tsx) · [草稿索引](../desktop/ui/App.tsx) · [提交时读取镜头和素材](../desktop/ui/App.tsx)

当时建议让每个镜头分别保存图片和视频草稿，包含提示词、模型、参数、首尾帧和参考素材顺序。打开新镜头时使用该镜的草稿，用户可选择沿用上一镜素材。草稿落盘需要保存可重新找到的素材引用，当前选取文件的临时编号在进程内维护。验收时，在第二镜提交前能看到准确的素材，返回第一镜或重开应用后能继续原稿。[素材编号与恢复](../src-tauri/src/store.rs)

### 作品整理与模型配置

- **整理长期积累的作品。** 目前作品库按关键词、媒体类型和任务状态查找。随着同一镜出现大量候选，可增加收藏、项目标签和归档，让日常选片更容易，也能保留旧作品与分镜的关联。即梦画布允许给重要节点加标签。[莫比环作品筛选](../desktop/ui/WorkLibrary.tsx) · [即梦资产管理](https://jimeng.jianying.com/tutorials/drama-studio/canvas)
- **每个模型单独声明能力。** 当前模型目录提取模型 ID，同连接共享协议和控制项。可允许某个模型覆盖尺寸、参考图上限、首尾帧、遮罩和多结果能力。切换时保留兼容的输入，并列出需要调整的字段，避免把服务端才会拒绝的组合交给用户试错。[模型发现](../src-tauri/src/catalog.rs) · [创作台参数来源](../desktop/ui/App.tsx)
- **导入已有的 ComfyUI 工作流。** 当前内置图使用固定节点，支持基础文生图及单张参考图重绘。可先支持导入 API 工作流，让用户标出提示词、参考图和结果节点，并检查所需节点和模型。ComfyUI 官方模板加载时会检查模型，Krita 插件也提供了调用自定义工作流的先例。[内置图](../src-tauri/src/comfy.rs) · [ComfyUI 模板](https://docs.comfy.org/interface/features/template) · [Krita 自定义工作流](https://docs.interstice.cloud/custom-graph/)

### 2.5.0 当时的优先顺序

先做镜头草稿隔离与自动保存、手工分镜、同镜候选对比。验收时，用户粘贴两镜脚本，分别选参考图、对照候选，关闭再打开后能从各镜上次的草稿与定稿继续。批量提交付费任务时，同步展示次数和已知预估。常做短片时，随后的优先项是角色参考复用和全片顺序预览。
